Music Chat Lab

Chatte mit Claude, Gemini und OpenAI, wechsle im laufenden Gespräch den Anbieter und hänge Musik- oder Dokumentdateien an.

MIDI und MusicXML werden lokal analysiert; API-Schlüssel bleiben auf diesem Gerät.

API-Einstellungen

Die Schlüssel bleiben im lokalen Speicher dieses Geräts und werden nicht in GitHub gespeichert.

Diese PWA ruft die Anbieter direkt aus dem Browser auf. Verwende sie nur auf eigenen, vertrauenswürdigen Geräten. Für eine öffentliche Mehrbenutzer-App wäre ein eigener Server für die Schlüssel erforderlich.
